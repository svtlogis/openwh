# Security Policy

OpenWH is an early-stage project. Do not use it with real customer or payment data until authentication, authorization, storage policies, and deployment configuration have been reviewed.

## Reporting a vulnerability

Please do not publish exploitable security details in a public issue. Contact the repository maintainer privately through the contact method listed on the GitHub profile.

Include:
- A description of the issue
- Steps to reproduce
- Potential impact
- Any suggested mitigation

Do not include real customer data, credentials, access tokens, or private package information in reports.
