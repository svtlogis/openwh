# Contributing to OpenWH

Thanks for your interest in contributing!

## Before you start

- Check existing issues before starting substantial work.
- For major changes, open an issue first to discuss the proposal.
- Keep changes focused and explain the problem they solve.
- Do not include real customer, shipment, payment, or personal data.

## Development workflow

1. Fork the repository.
2. Create a branch: `feat/short-description` or `fix/short-description`.
3. Install dependencies with `npm install`.
4. Run the app with `npm run dev`.
5. Run checks with `npm run lint` and `npm run build`.
6. Open a pull request with a clear summary and testing notes.

## Pull request checklist

- [ ] The change has a clear purpose.
- [ ] No secrets or personal data are included.
- [ ] UI changes work on mobile and desktop.
- [ ] Relevant tests or manual test steps are included.
- [ ] Documentation is updated when needed.
